# Chat System Frontend

This frontend scaffold contains the React app structure for the chat system.

## Structure

- `public/` - static HTML and assets
- `src/` - app source code
- `src/components/` - UI components
- `src/pages/` - route-level pages
- `src/services/` - API and auth service helpers
- `src/utils/` - utilities such as sockets and auth helpers
- `src/styles/` - global styling

## Notes

The files are placeholders and ready for actual chat UI and API integration.
